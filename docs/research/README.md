# Research Evidence Standard

Every research claim must distinguish verified source facts, deterministic calculations, interpretation, and hypothesis. Record source URI/provider, publication and observation timestamps, retrieval time, point-in-time availability, transformation, universe definition, code/strategy version, parameters, and limitations.

Never present synthetic fixtures as observed markets. Strategy evaluation requires out-of-sample, walk-forward, transaction-cost, robustness, and paper-trading evidence. Do not report profitability based only on an in-sample backtest.
